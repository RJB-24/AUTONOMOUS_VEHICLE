Create folders `blocked`, `forward`, `left`, and `right`. Capture from the mounted robot camera at 96x96 or larger. Labels describe the safest action, not merely obstacle position. Use multiple rooms, floor textures, obstacle shapes, and light levels. Keep recording sessions separated between training and test sets where possible; random adjacent video frames inflate test accuracy. Aim for at least 500 diverse frames per class for a prototype and balance all classes.
